# La Bandita

Este repositorio contiene el corpus de trabajo en `LaBandita.zip`. El punto de entrada para cualquier tarea nueva es la **[Guía de acción](GUIA-DE-ACCION.md)**; hay una copia dentro del ZIP en `00-CANON/CUATRO-ARCHIVOS/ARCHIVO-3-GUIA-DE-ACCION.md`.

## Prioridad actual — 1 de octubre de 2026

La meta es entregar algo que la persona pueda usar y comprobar. **No** se trabaja para canonizar el corpus, alcanzar una cuota de caracteres ni llenar archivos. Quedan retiradas como objetivos activos las metas fechadas del 27 de septiembre de 2,5 millones por archivo y 10 millones en conjunto. Los documentos anteriores siguen disponibles como contexto histórico; si una instrucción antigua choca con la petición más reciente, no se aplica como mandato vigente.

La extensión solo se mide cuando la tarea actual o un límite técnico real lo exige. No se alarga una pieza para cumplir una cifra.
