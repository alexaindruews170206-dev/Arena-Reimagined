# La Bandita — inicio del paquete

Este ZIP es una copia de distribución. Las fuentes de trabajo están en `docs/` del repositorio.

## Documentos vigentes

- [Tratado](TRATADO.md): propósito, principios, evidencia, autorización y criterio de cierre.
- [Manual](MANUAL-COMPLETO.md): pasos de trabajo y comprobaciones.
- [Mapa de acción](CANON-CIMIENTO.html): resumen visual e imprimible.
- [Lecciones de Alexis](LECCIONES-ALEXIS.md): origen y aplicación de enseñanzas seleccionadas.
- [Revisión de versiones](REVISION-DE-VERSIONES.md): alcance, cambios editoriales y estado de los antecedentes.
- Guía de acción: `CUATRO-ARCHIVOS/ARCHIVO-3-GUIA-DE-ACCION.md` dentro del ZIP; el archivo fuente del repositorio es `GUIA-DE-ACCION.md`.

## Versiones anteriores

Las copias congeladas se conservan bajo `_versiones/` y los materiales históricos, en las carpetas donde se produjeron. Son útiles para revisar procedencia; no son instrucciones activas si contradicen los documentos vigentes o la petición actual.

## Límites de esta edición

Esta revisión cubre el Tratado, el Manual, el Canon-Cimiento y las Lecciones de Alexis, además de las copias principales que los duplicaban. No certifica como vigente cada publicación, herramienta, enlace o material histórico que también contiene el ZIP. Verifica de nuevo los datos cambiantes antes de usarlos.

No hay una cuota de extensión ni una meta independiente de canonización. Cada documento debe tener el tamaño que su función requiera.
